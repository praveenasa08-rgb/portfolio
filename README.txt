# Student Portfolio

## Files
- `index.html` — page structure/content
- `style.css` — layout, colours, Flexbox, Grid, responsive design and themes
- `script.js` — theme toggle, mobile menu and form validation

## How to run
1. Put all three files in the same folder.
2. Open `index.html` in a browser.
3. Edit the text, links and project details.

## Topics covered from the syllabus
- HTML semantic structure
- Links, sections, forms and inputs
- CSS selectors
- Box model
- Flexbox
- CSS Grid
- Responsive design
- Media queries
- CSS variables
- JavaScript DOM selection
- JavaScript events
- Class toggling
- Form validation
- Regular expressions

## Important
The contact form is front-end validation only. It does not actually send an email until you connect it to a backend or form service.
